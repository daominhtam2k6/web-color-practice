
# Thực hành sử dụng màu sắc trong trang web

## Mục tiêu

Luyện tập phối màu đơn tông cho trang web bằng CSS.

## Phiên bản 1 - Màu xanh

Màu chủ đạo:

- #00ADEE
- #00B2EF
- #00BFF2
- #8DD7F7
- #C6E9FA

Trang chính sử dụng bảng màu xanh theo yêu cầu bài thực hành.

## Phiên bản 2 - Màu tím

Bảng màu đơn tông thứ hai:

- #7B2CBF
- #9D4EDD
- #C77DFF
- #E0AAFF
- #F3E8FF

File:

- Trang màu xanh: file HTML gốc
- Trang màu tím: index-purple.html
